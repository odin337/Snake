# odin337

Я строю веб-сервисы, инфраструктурные решения и AI-инструменты, где важны масштабируемость, ясная архитектура и стабильный результат.

## О себе

- Проектирую и развиваю веб-сервисы, API и внутренние инструменты.

- Работаю с AI-решениями, интеграциями и автоматизацией процессов.
