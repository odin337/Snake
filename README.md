# Snake

GitHub contributions snake animation for the profile of @odin337.

## Features
- Auto-generated SVG/GIF.
- Dark and light mode support.
- Daily GitHub Actions update.
- Ready to embed in profile README.

  <img src="https://raw.githubusercontent.com/odin337/Snake/output/ocean.gif" alt="Snake demo" />

## Usage
1. Fork or reuse the workflow.
2. Set your GitHub username.
3. Enable Actions permissions.
4. Embed the output SVG into your profile README.
